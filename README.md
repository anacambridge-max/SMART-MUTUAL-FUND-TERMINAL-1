# Smart Mutual Fund Decision Terminal

Standalone dashboard for a fixed 19-fund portfolio.

This project is intentionally independent from the older Smart SIP Dashboard.

## Scope
- Exactly 19 mutual funds
- Live market/index/sector context
- Biggest daily/weekly/monthly fallers
- Fund-relative weakness and trend checks
- Daily opportunity score
- Top 5 actionable opportunities
- Healthy correction vs structural weakness classification
- No portfolio/SIP tracker pages from the older application
